# 인스타그램 소개 캐러셀

서비스 외부 소개용 인스타그램 캐러셀 게시물 8장(1080×1350, 4:5 세로)과 캡션입니다.

| 파일 | 내용 |
|---|---|
| `slides/slide-1.png` ~ `slide-8.png` | 업로드용 이미지 (순서대로) |
| `carousel.html` | 원본 디자인 (문구 수정 시 이 파일을 고친다) |
| `render.mjs` | PNG 재생성: `node marketing/instagram/render.mjs` (Playwright·Google Fonts 접근 필요) |

## 슬라이드 구성

1. 커버 — 한국에서의 경험을, 일본 기업이 읽는 언어로.
2. 문제 제기 — ES·경어·직급 번역·비자 일정의 막막함
3. ES 첨삭 — 문장별 수정 이유를 한국어로 (예시 화면)
4. 일본식 모의면접 — 점수 없이 내용·경어·논리 피드백 + 꼬리질문 (예시 화면)
5. 자기분석 + 경력 번역 — STAR 카드, 代理（主任〜係長相当） (예시 화면)
6. 체크리스트 — 목표 입사 시기 기준 일정·서류·비자 (비자 고지 포함)
7. 원칙 — 평가·합격 예측 없음, 지어내지 않음, 일본어+한국어 해설, 운영자 검수, 데이터 관리
8. CTA — 무료/프로(19,900원/월) 플랜 비교, 프로필 링크

AI 예시가 들어간 슬라이드(3~5, 8)에는 앱과 같은 AI 고지 문구를 넣었습니다.
요금·한도는 `docs/DECISIONS.md` D19·D35 기준이므로, 바뀌면 8번 슬라이드도 함께 수정하세요.
