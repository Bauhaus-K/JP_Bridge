## MVP 이후 후보

- 실제 Anthropic API 로 프롬프트 품질 평가(eval 세트) 및 effort 조정
- 토스페이먼츠 빌링 연동 (`TossPaymentProvider`)
- 음성 면접 입력 (`AnswerInput` mode="voice")
- CSP(nonce), 오류 모니터링(Sentry 등)
- 리퍼럴: 법률 검토 후 동의 문구 확정·플래그 ON, 제휴사 API 연동은 범위 밖
